# Human Hemoglobin Protein Structure Analysis

## Project Overview
This beginner bioinformatics project explores the 3D structure of human hemoglobin using the PDB structure 1A3N.

## Objective
To study the structure of hemoglobin, identify its alpha and beta globin chains, and examine structural features and interactions between chains.

## Tools Used
- UCSF ChimeraX
- Protein Data Bank (PDB)

## Analysis Performed
- Visualization of the 3D protein structure
- Identification of alpha and beta globin chains
- Secondary structure analysis
- Molecular surface visualization
- Chain interaction and contact analysis

## Key Findings
- Hemoglobin contains four globin chains.
- Chains A and C represent alpha globin.
- Chains B and D represent beta globin.
- The structure shows a predominantly alpha-helical arrangement.
